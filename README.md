# TaskFlow

**Organize suas tarefas. Acompanhe suas atividades. Evolua sua produtividade.**

O **TaskFlow** é uma aplicação web de gerenciamento de tarefas desenvolvida com React e JavaScript. Seu objetivo é facilitar a organização de atividades por meio de uma interface intuitiva, moderna e responsiva.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em desenvolvimento frontend, colocando em prática conceitos fundamentais de programação e desenvolvimento de interfaces.

## Sobre o projeto

O TaskFlow permite organizar tarefas, acompanhar seu progresso e gerenciar atividades de maneira simples e eficiente.

A aplicação conta com uma interface em tema escuro, navegação intuitiva e adaptação para diferentes tamanhos de tela, proporcionando uma experiência consistente tanto em computadores quanto em dispositivos móveis.

## Funcionalidades

- **Adicionar tarefas:** crie novas atividades.
- **Editar tarefas:** atualize o conteúdo das atividades.
- **Remover tarefas:** exclua atividades da lista.
- **Concluir tarefas:** marque atividades como concluídas ou pendentes.
- **Filtros:** visualize todas as tarefas, somente as pendentes ou as concluídas.
- **Estatísticas dinâmicas:** acompanhe a quantidade total, pendente e concluída.
- **Validação de dados:** impede o cadastro de tarefas vazias ou duplicadas.
- **Persistência de dados:** mantém as tarefas salvas utilizando LocalStorage.
- **Interface responsiva:** layout adaptado para desktop e dispositivos móveis.

## Tecnologias utilizadas

- **React** — construção de interfaces utilizando componentes e gerenciamento de estado.
- **JavaScript** — lógica e interatividade da aplicação.
- **Vite** — ferramenta de desenvolvimento e build.
- **CSS3** — estilização, layout e responsividade.
- **LocalStorage** — armazenamento local das tarefas no navegador.
- **Git e GitHub** — versionamento e gerenciamento do código-fonte.

## Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm, incluído na instalação do Node.js.
- Git.

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/devthierry-sky/TaskFlow.git
```

2. Entre na pasta do projeto:

```bash
cd TaskFlow
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Abra no navegador o endereço exibido no terminal.

### Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão gerada localmente:

```bash
npm run preview
```
